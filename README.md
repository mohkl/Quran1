# Quran — تطبيق القرآن الكريم

تطبيق أندرويد متكامل للقرآن الكريم: **قراءة المصحف بالصور، التفسير الكامل، الاستماع للتلاوات، والمسبحة الإلكترونية.**

![Logo](app/src/main/res/mipmap-xxxhdpi/ic_launcher.png)

## المميزات

- قراءة المصحف كاملاً (604 صفحة بصور المصحف عالية الجودة) مع حفظ آخر صفحة والانتقال المباشر لأي صفحة
- التفسير الكامل لجميع السور (114 سورة) بثلاثة تفاسير: **تفسير ابن كثير، تفسير السعدي، التفسير الوسيط**
- الاستماع لجميع السور كاملة بصوت:
  - الشيخ **مشاري راشد العفاسي**
  - الشيخ **ناصر القطامي**
- مسبحة إلكترونية بعدادات واهتزاز وهدف (33/100/1000) وحفظ الإحصائيات
- شاشة معلومات المطور مع زر واتساب مباشر
- تصميم عصري بألوان GitHub (داكن مع لمسات خضراء وذهبية) ودعم الوضع الليلي والنهاري

## بناء ملف APK تلقائياً عبر GitHub

1. أنشئ مستودعاً جديداً على GitHub وارفع هذا المشروع إليه
2. ادخل إلى تبويب **Actions** — سيبدأ البناء تلقائياً
3. بعد نجاح البناء، حمّل ملف `app-debug.apk` من قسم **Artifacts**
4. لإصدار رسمي: أنشئ **Release** جديداً وسيُرفق ملف APK تلقائياً
